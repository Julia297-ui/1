## 0. Правила работы (для Claude)

1. Отвечай по-русски, коротко и по цифрам. Используй горизонтальные компактные таблицы, артикулы сортируй по возрастанию, если не попросили иначе.
2. Если выгрузка отличается от описанной (новые или переименованные колонки, другой лист), сначала сравни структуру и коротко скажи, что изменилось. Потом считай.
3. Каждая статья берётся ровно один раз. Перед ответом сверь сумму статей с итогом выгрузки. Если не сходится, скажи об этом прямо и не подгоняй цифры.
4. Если у товара нет себестоимости, выведи список пропусков отдельно. Не исключай такие товары молча и не подставляй себестоимость наугад.
5. **Тело кредита («Займы и факторинг») никогда не прибавляется к марже и не вычитается из неё**, даже если об этом просят. Рентабельность «без кредита» — это маржа без процентов по кредиту. Тело кредита показывается только в блоке «Деньги на счёт» (см. раздел 3).
6. Результат по умолчанию — Excel-файл в формате из раздела 5 плюс короткий разбор в ответе. Если нужен MD, сделай MD.
7. Налог по умолчанию 10% от чистой выручки (продажи минус возвраты), если пользователь не назвал другую ставку. Для киргизского кабинета WB налога нет.

## 2. Ozon — отчёт по начислениям

**Вход:** «Отчёт по начислениям» (xlsx), лист «Начисления». В строке 1 «Период», в строке 2 шапка, данные с третьей строки.
Рабочие колонки: «Группа услуг», «Тип начисления», «Артикул», «Количество», «Сумма итого, руб.».

### Главный принцип
«Сумма итого» — это готовое движение денег. Сумма всех строк равна начислению за период. Ничего не вычитать повторно.

### Статьи

| Статья | Откуда |
|---|---|
| Выручка | группы «Продажи» + «Возвраты» |
| Комиссия Ozon | группа «Вознаграждение Ozon» |
| Логистика и услуги партнёров | «Услуги доставки» + «Услуги партнёров» |
| Реклама | «Продвижение и реклама» |
| Проценты по кредиту | типы «Досрочная выплата» + «Гибкий график выплат» |
| Хранение, FBO, штрафы | всё остальное: «Услуги FBO», «Другие услуги и штрафы», «Компенсации и декомпенсации», без процентов |
| Себестоимость | (продано − возвращено) × стоп-цена модели |
| Налог | 10% × выручка |

Продано — «Количество» по типу «Выручка», возвращено — по типу «Возврат выручки».

### Формулы
```
Маржа          = итог всех начислений − себестоимость − налог
Маржа без кр.  = маржа + |проценты по кредиту|
Рентабельность = маржа / выручка
ROI к закупке  = маржа / себестоимость
```

### Важно знать
- Выручка Ozon — это цена продавца: деньги покупателя плюс «Баллы за скидки» и «Программы партнёров». Больше половины выручки — баллы. Комиссия считается от полной цены, поэтому 48–52% — норма, а не ошибка.
- Строки без артикула (реклама, хранение, кросс-докинг, страхование, досрочка) при разбивке по SKU разносятся пропорционально выручке: доля = выручка SKU / сумма группы «Продажи». На общий итог это не влияет.
- Сверка с кабинетом: все группы услуг в виджете «Начисления» совпадают с выгрузкой до рубля. Единственное расхождение — «Займы и факторинг»: `итог выгрузки − займы = «Итого» в кабинете`.

## 3. Кредит («Займы и факторинг»)

- Тела кредита нет в отчёте по начислениям. Ozon удерживает его после начислений, сумма видна только в кабинете.
- **Тело кредита не является ни доходом, ни расходом.** Это возврат денег, полученных раньше авансом под ту же выручку. Если вычесть его из маржи или прибавить к ней, одни деньги будут посчитаны дважды.
- Расход по кредиту — только проценты (досрочная выплата и гибкий график). Они уже входят в маржу.
- В отчёте всегда два отдельных блока:

| Блок | Содержание |
|---|---|
| Прибыль | маржа «Факт» и «Без кредита» (без процентов) |
| Деньги на счёт | начислено − гашение тела (жёлтая ячейка, вводится из кабинета) = поступило |

## 4. Wildberries — еженедельный детализированный отчёт

**Вход:** 1–2 файла «Еженедельный детализированный отчёт № …». Если файлов несколько, объединить их. Колонки ищутся по названию, не по букве.

### Главный принцип
Колонка «К перечислению Продавцу за реализованный Товар» **уже очищена** от вознаграждения WB, НДС с него, ПВЗ и эквайринга. Проверено на всех строках продаж:
`Реализовано − ВВ − НДС с ВВ − ПВЗ − эквайринг = К перечислению` (отклонение ≤ 0,005 ₽).

### Статьи

| Статья | Откуда |
|---|---|
| Реализовано / Возвраты | «Вайлдберриз реализовал Товар (Пр)» по «Обоснованию» = Продажа / Возврат |
| К перечислению | Продажа − Возврат + «Коррекция продаж» − «Коррекция возвратов» + «Добровольная компенсация при возврате» |
| Комиссия WB (справочно) | К перечислению − (Реализовано − Возвраты) |
| Логистика | «Услуги по доставке товара покупателю» |
| Хранение | «Хранение» |
| Реклама | «Удержания», строка «Оказание услуг «WB Продвижение»» |
| Прочие удержания | остальное в «Удержаниях» (списания за отзывы и т. п.) |
| Штрафы | «Общая сумма штрафов» |
| Компенсация лояльности | «Компенсация скидки по программе лояльности» (это доход, со знаком плюс) |
| Доплата | **в отчёте нет**, вводится вручную, если пользователь её назвал |

### Чего НЕ вычитать (ловушки двойного счёта)
- **ПВЗ** («Возмещение за выдачу и возврат товаров на ПВЗ») уже внутри «К перечислению». Отдельные строки ПВЗ тоже не вычитать, так считает система пользователя.
- **Перевозка/перемещение** («Возмещение издержек по перевозке…», с сентября 2026 — «…по перемещению и операционной обработке товара»). Это взаимозачёт: на этих строках ВВ + НДС + возмещение = 0, а «К перечислению» = 0.

### Формулы
```
Маржа = К перечислению − логистика − хранение − удержания − штрафы
        + компенсация лояльности + доплата − себестоимость − налог
Налог = 10% × (Реализовано − Возвраты)
Рентабельность к выручке = маржа / (Реализовано − Возвраты)
ROI к закупке            = маржа / себестоимость   ← так считает система пользователя
```
Всегда показывай обе базы и подписывай, какая из них какая.

### Изменения формата (сентябрь 2026)
Колонки переименованы: «Виды логистики…» → «Виды доставок, штрафов и корректировок ВВ», «Коэффициент логистики» → «Коэффициент доставки». Обоснование «Логистика» стало «Доставка». Появились «Коррекция продаж» и «Коррекция возвратов», они учитываются в «К перечислению».

### Киргизский кабинет (SVETEKST, нерезидент)
- Есть колонка «Удержание Агентского НДС» (≈18% от реализации, то есть 22/122). **Она НЕ входит в «К перечислению»**, её вычитают отдельно.
- Налога 10% нет.
- Себестоимость тоже сопоставляется по штрихкоду.

## 5. Форматы результата

### А. Недельная рентабельность (Ozon или WB)
Excel, один лист:
1. **Прибыль за неделю**: строки статей из раздела 2 или 4, колонки «Факт», «Без кредита», «Прошлая неделя» (если есть прошлая выгрузка). Внизу маржа, рентабельность к выручке и ROI к закупке.
2. **Деньги на счёт**: начислено, гашение тела кредита (жёлтая ячейка для ввода), поступило (формула).
3. **Показатели**: продано, возвраты (шт и %), средний чек, комиссия к выручке, логистика к выручке, ДРР, себестоимость к выручке, SKU с продажами, SKU в минусе и сумма убытка по ним, проценты по кредиту к марже.
4. **Комментарий справа**: 4–6 коротких выводов — что изменилось к прошлой неделе и почему.

### Б. Маржа на артикул (шаблон пользователя)
Одна строка на модель, все размеры и цвета модели сведены вместе. Колонки:

`Наименование | Продано шт | Продажа ₽ | Возврат шт | Возврат ₽ | Логистика | Хранение | Реклама % | Стоп-цена | СТОП-ЦЕНА | Итого | Налог | ИТОГОВЫЙ ИТОГ | Маржа | Рентабельность | Маржа на ед. | Статус`

```
СТОП-ЦЕНА      = стоп-цена × (продано − возвращено)
Итого          = (Продажа − Возврат) − Логистика − Хранение − (Продажа − Возврат) × Реклама%
Налог          = (Продажа − Возврат) × ставка (одна ячейка на лист)
ИТОГОВЫЙ ИТОГ  = Итого − Налог
Маржа          = ИТОГОВЫЙ ИТОГ − СТОП-ЦЕНА
Рентабельность = Маржа / СТОП-ЦЕНА
Статус         = ЕСЛИ(Маржа<0; "В МИНУСЕ"; "в плюсе"), с красной или зелёной подсветкой
```
- Для WB «Продажа» и «Возврат» — это суммы к перечислению. Реклама по умолчанию 5% (норматив), потому что по артикулам её в отчёте нет.
- Для Ozon реклама фактическая: общий пул без артикула разносится по выручке. Комиссия и прочие услуги идут отдельными колонками.
- Колонку «5% наш процент» **не использовать**, пользователь её убрал.
- Всё на формулах, входные данные в жёлтых ячейках. Внизу блок «Экономика одной единицы».

## 8. Типовые ошибки

| Ошибка | Последствие |
|---|---|
| WB: вычесть ПВЗ отдельно | занижение маржи на ~100 тыс. ₽ в неделю |
| WB: вычесть «Возмещение издержек по перевозке/перемещению» | занижение на ~90–120 тыс. ₽ |
| WB: забыть рекламу в «Удержаниях» | завышение на ~200 тыс. ₽ |
| Киргизия: не вычесть агентский НДС | завышение на ~20% выручки |
| Ozon: считать выручкой только деньги покупателя | выручка вдвое ниже, комиссия выглядит как 100%+ |
| Прибавить или вычесть тело кредита | маржа искажается на сотни тысяч |
| Сравнить ROI одной площадки с рентабельностью к выручке другой | разные базы, вывод неверный |
| Брать стоп-цены из старого шаблона (Палаццо 496, Лапша 580, Фасон 666) | маржа завышена; брать только из актуального файла цен |
