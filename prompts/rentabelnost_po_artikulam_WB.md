# Промпт: поартикульная рентабельность по финансовому отчёту WB

Скопируй текст ниже целиком и отправь вместе с файлами.

---

Ты — финансовый аналитик маркетплейса Wildberries. Посчитай рентабельность каждого артикула продавца по детализации еженедельного финансового отчёта WB. Результат — Excel-файл, в котором **все расчётные ячейки — живые формулы**, а не вписанные числа.

## Исходные данные

1. **Детализация финансового отчёта WB** (одна или несколько недель, xlsx/csv из «Финансовые отчёты → Детализация», или выгрузка API `reportDetailByPeriod` / `sales-reports/detailed`).
2. **Себестоимость**: таблица «Артикул продавца → себестоимость 1 шт, ₽». Если её нет — создай лист «Себестоимость» с пустыми жёлтыми ячейками для ввода, формулы должны пересчитаться после заполнения.
3. Период отчёта: [дата начала] – [дата окончания].

## Правила обработки

1. **Артикул без размеров.** Группируй по «Артикулу поставщика» (`sa_name`), отбрасывая размер. Если размер вшит в артикул (например `Футболка_680/черный_48` или `...-48`), отрежь его по шаблону и перечисли в отчёте, какие правила отсечения применил.
2. **Знак операции** определяй по столбцу «Тип документа» (`doc_type_name`): «Продажа» — плюс, «Возврат» — минус. Для строк корректировок ориентируйся на «Обоснование для оплаты» (`supplier_oper_name`).
3. **Расходы, у которых нет артикула** (хранение, платная приёмка, прочие удержания, штрафы без артикула), распредели по артикулам пропорционально выручке «Вайлдберриз реализовал Товар (Пр)» за период. Вынеси базу распределения в отдельный столбец, чтобы её можно было поменять (например, на количество проданных штук).
4. Ничего не выдумывай: если какого-то столбца нет в отчёте, оставь соответствующую статью нулём и перечисли такие статьи в конце.

## Структура книги Excel

**Лист «Детализация»** — исходные строки отчёта без изменений плюс вспомогательные столбцы:
- `Артикул (без размера)` — формула или значение после очистки;
- `Знак` = `ЕСЛИ(Тип документа="Возврат";-1;1)`.

**Лист «Себестоимость»** — Артикул | Себестоимость 1 шт, ₽.

**Лист «Рентабельность»** — одна строка на артикул. Столбцы и формулы (ссылки — по строке 2, протянуть вниз; `Д` = лист «Детализация»):

| Столбец | Показатель | Формула |
|---|---|---|
| A | Артикул продавца (без размера) | уникальный список |
| B | Продано, шт | `=СУММЕСЛИМН(Д!Кол-во;Д!Артикул;A2;Д!Тип документа;"Продажа")` |
| C | Возвраты, шт | `=СУММЕСЛИМН(Д!Кол-во;Д!Артикул;A2;Д!Тип документа;"Возврат")` |
| D | Чистые продажи, шт | `=B2-C2` |
| E | Выручка (реализовано ВБ), ₽ | `=СУММЕСЛИМН(Д!Пр продажа;Д!Артикул;A2;Д!Тип документа;"Продажа")-СУММЕСЛИМН(Д!Пр;Д!Артикул;A2;Д!Тип документа;"Возврат")` |
| F | К перечислению продавцу за товар, ₽ | `=СУММЕСЛИМН(Д!К перечислению;Д!Артикул;A2;Д!Тип документа;"Продажа")-СУММЕСЛИМН(Д!К перечислению;Д!Артикул;A2;Д!Тип документа;"Возврат")` |
| G | Логистика, ₽ | `=СУММЕСЛИМН(Д!Услуги по доставке;Д!Артикул;A2)` |
| H | Штрафы, ₽ | `=СУММЕСЛИМН(Д!Общая сумма штрафов;Д!Артикул;A2)` + доля штрафов без артикула |
| I | Хранение, ₽ | `=СУММЕСЛИМН(Д!Хранение;Д!Артикул;A2)` + доля хранения без артикула (`=Итого хранение без артикула*E2/СУММ($E:$E)`) |
| J | Платная приёмка, ₽ | аналогично I |
| K | Прочие удержания, ₽ | аналогично I |
| L | Доплаты/компенсации, ₽ | `=СУММЕСЛИМН(Д!Доплаты;Д!Артикул;A2)` |
| M | **Итого к перечислению на р/с за вычетом расходов МП, ₽** | `=F2-G2-H2-I2-J2-K2+L2` |
| N | Себестоимость 1 шт, ₽ | `=ЕСЛИОШИБКА(ВПР(A2;Себестоимость!A:B;2;0);"")` |
| O | Себестоимость проданного, ₽ | `=ЕСЛИ(N2="";"";N2*D2)` |
| P | **Рентабельность, ₽** | `=ЕСЛИ(O2="";"";M2-O2)` |
| Q | **Рентабельность, %** | `=ЕСЛИ(ИЛИ(O2="";O2=0);"";P2/O2)` — формат «0,0%» |
| R | Доля в выручке, % | `=E2/СУММ($E$2:$E$N)` |

Итоговая строка внизу: суммы по B–M, O, P и средневзвешенная рентабельность `=P_итог/O_итог`.

**Ключевые формулы (не менять смысл):**
- Рентабельность, ₽ = сумма к перечислению на р/с за вычетом всех расходов МП − себестоимость проданного.
- Рентабельность, % = Рентабельность, ₽ / себестоимость проданного.

## Проверки (выведи результат каждой)

1. Сумма столбца M по всем артикулам равна «Итого к оплате» финансового отчёта за период (допуск ±1 ₽). Если не равна — покажи разницу и её причины.
2. Нет артикулов без себестоимости. Если есть — список, они подсвечены жёлтым.
3. Нет строк отчёта, не попавших ни в один артикул (кроме распределённых расходов).

## Что выдать

1. Файл Excel с тремя листами и формулами.
2. Краткую сводку в чате:
   - топ-10 и анти-топ-10 артикулов по рентабельности в ₽ и в %;
   - список убыточных артикулов;
   - средняя рентабельность по кабинету;
   - на какие статьи расходов МП приходится больше всего денег.
3. Список допущений: правило отсечения размера, база распределения расходов без артикула, отсутствующие столбцы.
