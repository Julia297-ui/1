# Рич-контент для комбинезонов (вариант A)

Картинки 1440×1440 px, JPG. Порядок блоков одинаковый для всех карточек:

1. `01_oblozhka.jpg` — общая обложка «Тёплая флисовая поддева 62–122 см»
2. `02_kak_nosit.jpg` — «Не будет ли холодно?» и схема слоёв
3. `03_detali_<модель>.jpg` — детали **своей** модели
4. `04_razmer_<модель>.jpg` — размерная таблица **своей** модели
5. `05_material.jpg` — «Мягкий флис» и совет по уходу
6. `06_lineyka.jpg` — «Растём вместе», вся линейка

Замеры в таблицах взяты из размерных сеток на фото ваших карточек. У 106ФЛ6F такой сетки нет, поэтому в таблице только рост и возраст. Пришлите замеры — добавлю.

Загрузка: кабинет → Товары → Карточки товаров → карточка → «Рич-контент». Через API рич-контент не загружается.
