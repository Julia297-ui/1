# Рич-контент комбинезонов 800×500 — по артикулам

В каждой папке — 6 слайдов одной модели, по порядку: 1 → 6. Имя файла: модель_номер_блок.
В `артикулы.txt` — артикулы WB, в которые загружать этот комплект.
Подписи на самих картинках не ставились: их увидят покупатели.

Загрузка: кабинет → Товары → Карточки товаров → карточка → «Рич-контент».
