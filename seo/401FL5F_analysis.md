## 2. Что не так

### Наименование
«Блузка школьная нарядная с длинным рукавом» — 42 символа из 60, одинаковое с 401ФЛ8F. Нет «для девочки» (главный запрос «блузка школьная для девочки» — 36 тыс./мес), нет отличия модели — **кружевного жабо / воланов / рюш**.
Покупатели ищут такую блузку как «блузка с рюшами» (2,5 тыс./мес), «блуза с рюшами» (1 тыс.), «лонгслив с рюшами для девочки», «блузка с воланами школьная», «водолазка для девочки школьная» (8,1 тыс.) — слово «жабо» в запросах почти не встречается.

### Описание
- **«Модель представлена в размерном ряду 128–158»**, «для девочек и подростков», «для девочек разного возраста» — про размеры/возраст (договорились не писать).
- «Школьная форма для девочек сохраняет форму» — блузку назвали формой, звучит как вставка ключевика.
- «Во время активных игр», «подчёркивая хрупкость и изящество, но не обтягивая» — шаблон.
- Нет: кружево на жабо, мягкая стойка, с чем носить (юбка, сарафан, брюки, жилет), цвета.

### Фото
- 8–14 фото, все — «чистые» снимки без инфографики (у молочного только 8).
- **Нет**: главного фото с инфографикой, размерной сетки, вида со спины, слайда ухода за кружевом. В «Кактусе» у этой модели есть инфографика на главном фото и выноски «кружевное жабо», «приятная к телу ткань».

### Рич
В наборе рича v3 эта модель сейчас отнесена к «без кружева» (по полю «Декоративные элементы: жабо»). На фото жабо кружевное → правильнее давать ей набор **«с кружевом»** (со слайдом «Как сохранить кружево»).

| B | Блузка школьная для девочки с рюшами и длинным рукавом | 54 |
| C | Блузка водолазка школьная для девочки с кружевным жабо | 54 |

A — главный запрос «блузка школьная для девочки» + «нарядная» + отличие модели словами покупателей («воланы»). B — ловит «с рюшами» и «с длинным рукавом». C — для «водолазочных» запросов, как у 401ФЛ8F.

## 4. Описание

Нарядная школьная блузка для девочки с каскадом кружевных воланов на груди — та самая вещь, которая делает обычный школьный день немного праздничным. Модель сшита из мягкого хлопкового трикотажа с эластаном: ткань приятна к коже, дышит, хорошо тянется и не сковывает движений на уроках и переменах. Высокий воротник-стойка мягко облегает шею, длинные рукава с аккуратной обработкой сохраняют опрятный вид весь день, а полуприлегающий силуэт красиво садится по фигуре и удобно заправляется в юбку или брюки. Главный акцент — нежное кружевное жабо: воланы мягко спадают каскадом и придают образу женственность без лишней вычурности. Однотонная блуза легко сочетается со школьной формой — сарафаном, жилетом, юбкой-плиссе или классическими брюками, а вне школы её можно носить с джинсами и кардиганом. Подходит для уроков, линейки, концертов, выступлений, олимпиад, театра и семейных праздников. Палитра из восьми цветов — белый, молочный, голубой, розовый, сиреневый, серый, тёмно-синий и бордовый — позволяет подобрать оттенок под любой дресс-код школы. Трикотаж держит форму и цвет после стирок, поэтому кофточка надолго остаётся любимой. Детская одежда TOTEMFOX — продуманные детали и удобство для школы и праздников.

Сплошной текст без размеров, возраста и ухода.

## 6. Рекомендации вне карточки
1. **Поставить товар** — без остатков карточки не продают. Начать с цветов-лидеров «Кактуса»: т.синий, голубой, сиреневый, молочный, серый, бордовый; белый — к весне/линейкам.
2. **Цена**: на старте держать не выше «Кактуса» (1 050–1 200 ₽ до СПП), пока нет отзывов.
3. **Фото**: главное с инфографикой («Кружевные воланы», «Мягкий хлопок», «Размеры 128–158»), размерная сетка, вид со спины, слайд «Как сохранить кружево» (уже есть для других блузок — можно поставить 5-м, как в 38 карточках).
4. **Рич**: перенести модель в набор блузок «с кружевом».
5. **Размер 122**: есть в мастер-файле — добавить в карточки, если шьётся.
6. **Отзывы**: после поставки — «Отзывы за баллы», чтобы быстрее набрать первые 10–20.
