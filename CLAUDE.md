# Правила для карточек Wildberries (магазин DABL LAVL)

## Наименование
- Пол в наименовании не прописываем (никаких «женские», «мужские», «для девочек» и т. п.). Пол указывается только в характеристике «Пол».
- Длина наименования — до 60 символов.

## Описание
- Описание пишем сплошным текстом: один абзац, без переносов строк, списков и заголовков.
