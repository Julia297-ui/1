# Расчёты для маркетплейсов WB и Ozon

- Правила расчёта рентабельности — `docs/rentabelnost_wb_ozon.md`. Следовать им буквально,
  отвечать по-русски, коротко и по цифрам.
- Ozon: `python3 ozon_profitability.py НАЧИСЛЕНИЯ.xlsx Цены_ВБ_себесы.xlsx [-p ПРОШЛАЯ.xlsx] [--credit-body N]`
  — даёт Excel (недельная рента + маржа по моделям + пропуски себестоимости) и сводку в консоль.
  Перед расчётом сверить структуру выгрузки с инструкцией; предупреждения скрипта пересказать пользователю.
- Себестоимость не придумывать: нет файла цен — попросить его.
